# EMSC2010 – Group Project Template

This repository contains the template Jupyter notebook used for **weekly group projects** in *EMSC2010: Data Science for Earth System Scientists* at the Australian National University.

Unlike the weekly lectorial and practical repositories, this template is designed to be used repeatedly by each project group — providing a consistent structure for project documentation, role allocation, quality control, and the analysis itself.

---

## Notebook

### Group Project Template (`EMSC2010_Group_Project_template.ipynb`)

This notebook combines project record-keeping with the analysis workspace. It is structured as follows:

**1. Project Overview** — group name, project week, project title, and a list of datasets used (name and source).

**2. Roles and Contributions** — a table assigning a Primary and Deputy group member to each of six project roles (GitHub & integration, Data steward, Analysis/modelling, Visualisation/interpretation, Narrative, Quality Control/Reproducibility), with columns to record completion status and notes.

**3. Deputy Interventions** — an optional, factual record of any instances where a Deputy had to step in for a Primary (e.g. due to a missed deadline or absence), including the role affected, reason, action taken, and impact on the workflow.

**4. Pre-submission Checklist** — a checklist confirming the notebook runs top-to-bottom, all data files are included in the repository, commits are meaningful, each group member has added a brief reflection, and the repository has been shared with the teaching team.

**5. Project Workspace** — a blank section ("Start your group project here") where the group builds out their actual analysis.

**Key concepts:** Group project structure, role allocation and accountability, reproducibility checklist, collaborative GitHub workflow

**Libraries:** None specified — group members add the packages required for their chosen analysis

## Getting Started

This is a **template repository**, intended to be reused for each weekly group project.

1. Click **"Use this template"** at the top of this page to create a new copy of the repository for your group (e.g. one copy per project week, or one shared repository reused across weeks — follow your teaching team's instructions).
2. Open `EMSC2010_Group_Project_template.ipynb` from your copy of the repository and click the **"Open in Colab"** badge to launch it in Google Colab.
3. Fill in the **Project Overview** and **Roles and Contributions** sections at the start of the project.
4. Build your analysis in the workspace section at the end of the notebook, including any data files in the repository.
5. Before submission, complete the **Pre-submission Checklist** and ensure the repository has been shared with the teaching team.
